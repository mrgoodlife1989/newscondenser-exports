# NewsCondenser - Daily AI News exports

Machine-readable exports of the daily AI News brief, published for the Android app.

- stories-latest.json - always the most recent run. Stable URL for the app.
- stories-YYYY-MM-DD.json - dated history, one file per run.

Raw URL the app should fetch:
https://raw.githubusercontent.com/mrgoodlife1989/newscondenser-exports/main/stories-latest.json
